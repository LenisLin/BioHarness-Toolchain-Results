# BioHarness Results

This is the canonical result storage tree for BioHarness project data.

## Directories

- `layer1/`: source Layer 1 method-registry result artifacts.
- `layer2/`: source Layer 2 topic artifacts.
- `layer3_4/`: downstream engineering workspace outside the current formal Layer 1/2 reading pass.
- `formal/`: normalized reading and handoff entry for current formal Layer 1/2 knowledge artifacts.

The `formal/` directory does not replace, move, or rewrite the source artifacts in `layer1/` or `layer2/`. It provides a stable entry point for readers and handoffs that need the current Layer 1/2 boundary and source map.

Scratch outputs, historical run notes, compatibility symlinks, and staged historical reports are intentionally not kept here.
