# BioHarness Results

This is the canonical result storage tree for BioHarness project data.

## Directories

- `layer1_method_registry/`: current Layer 1 method-registry result artifacts.
- `layer2/spatial_domain_identification/`: current spatial domain identification Layer 2 artifacts and closure note.

Scratch outputs, historical run notes, compatibility symlinks, and staged historical reports are intentionally not kept here.
