# Method Audits

This directory stores engineering-stage method audit artifacts for promoted Layer 2 methods.

Method audits are not runtime APIs and do not claim production execution support. They consolidate source evidence, Layer 2 handoff constraints, code mind maps, Layer 3 functional implications, and Layer 4 binding evidence so separate Layer 3 `ExecutionSurfaceSpec` and Layer 4 `BackendAdapterSpec` drafts can be reviewed.
