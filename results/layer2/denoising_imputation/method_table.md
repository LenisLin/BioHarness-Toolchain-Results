## Status

Layer served: `Layer 2`

This table is the human-readable method-selection table for the frozen
`Denoising / Imputation` candidate set. It is not a runtime support matrix and
does not define commands, adapters, environment capsules, or callable surfaces.

## Table Notes

- `SpotGF` is intentionally retained as a boundary denoising/gene-filtering row.
- `Memory Burden` and `Scale Sensitivity` stay conservative; `unclear` is used
  when public evidence is not direct enough for a stronger label.
- `Code Access = available` records that a primary source was found. It does
  not imply that BioHarness currently supports runtime execution.
