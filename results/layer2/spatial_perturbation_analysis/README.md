# Spatial Perturbation Analysis Layer 2 Package

## Status

Layer served: `Layer 2`

Package status: complete working/evidence package for the frozen `Spatial Perturbation Analysis` candidate set.

This package supports method selection. It is not a Layer 3 execution surface, Layer 4 implementation, adapter specification, environment binding, callable signature, or runtime-support claim.

## Candidate Freeze

The frozen candidate set has five methods:

- `CONCERT`
- `Celcomen`
- `Spatial-ZEDNet`
- `River`
- `Perturb-STNet`

`Spatial-ZEDNet`, `River`, and `Perturb-STNet` were added by human approval after a 2026-05-02 targeted boundary check focused on 2025-2026 spatial perturbation methods. `CDS` / counterfactual directional cell-cell influence is treated as a Cell-Cell Communication boundary item and is not included here.

## Boundary Note

This topic covers spatial perturbation-response modeling, causal/counterfactual tissue perturbation modeling, observed spatial perturbation-effect detection, perturbation-responsive spatial pattern prioritization, and spatiotemporal perturbation regulator prioritization. It does not cover generic differential expression, descriptive spatial domain detection, cell-cell communication inference without perturbation response/effect modeling, assay/workflow-first spatial perturbation technologies, or runtime execution planning.
