## Table Notes

- `VistoSeg` is retained as a histology or IF image-processing support row, not as a direct cell-boundary or transcript-assignment method.
- `Spotiflow` and `Piscis` are retained as transcript spot-detection rows; spot coordinates are not cell masks or transcript-to-cell assignments.
- `CelloType` is retained as a joint image segmentation/classification boundary row and should only be used when classification coupling is intended.
- `segger` remains preprint-level in this package; scale and accuracy claims require independent replication.
- Code access records trace metadata only. Code/access trace is metadata only; no Layer 3 runtime, callable, adapter, or environment support implied.
