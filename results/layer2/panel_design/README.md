# Panel Design Layer 2 Working Package

This package supersedes the feature-selection branch of the former `Normalization / Feature Selection` topic. It covers pre-assay gene/probe panel design for targeted spatial transcriptomics.

Current candidate freeze: `scGIST`, `gpsFISH`, `Spapros`, `PERSIST`, and caveated preprint/watchlist row `ReconST`.

For `ReconST`, reconstruction or spatial-pattern language is treated as a panel-evaluation objective, not spatial location reconstruction, expression-map reconstruction, super-resolution, or gene-expression prediction output.

Excluded or related but not positive for this topic: `SUICA` belongs near super-resolution / expression enhancement, `DeepLinc` belongs near cell-cell communication / interaction landscape, and `stMCDI` belongs near denoising / imputation.
