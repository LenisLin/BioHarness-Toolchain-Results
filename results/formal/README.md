# Formal Results Entry

This directory is the normalized reading and handoff entry for current BioHarness result artifacts.

At this stage, `formal/` organizes only Layer 1 and Layer 2 knowledge artifacts. It does not replace, relocate, or rewrite the source artifacts, which remain in the original `results/layer1/` and `results/layer2/` directories.

The `layer3_4/` directory is a downstream engineering workspace and is outside the scope of this formal Layer 1/2 organization pass.

## Entries

- `SOURCES.md`: file-level source map for the current formal reading entry.
- `LAYER_BOUNDARY.md`: layer boundary and current-state note.
- `layer1/`: formal Layer 1 entry point.
- `layer2/`: formal Layer 2 entry point.
