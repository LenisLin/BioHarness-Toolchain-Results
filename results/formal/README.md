# Formal Results Entry

This directory is the normalized agent-facing reading and handoff entry for current BioHarness Layer 1 and Layer 2 result artifacts.

`formal/` organizes compact knowledge artifacts for problem routing and method selection. It does not replace, relocate, or rewrite the source artifacts, which remain in the original `results/layer1/` and `results/layer2/` directories.

Layer 3/4 engineering workspaces are outside the scope of this formal Layer 1/2 organization pass.

## Entries

- `SOURCES.md`: file-level source map for the current formal reading entry.
- `LAYER_BOUNDARY.md`: layer boundary and current-state note.
- `layer1/`: formal Layer 1 problem-routing entry point.
- `layer2/`: formal Layer 2 method-selection entry point and topic files.
