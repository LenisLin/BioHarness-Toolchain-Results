# Layer Boundary

Layer 1 is the evidence, routing, and catalog level. It records method existence and task-family placement for reader orientation and later routing work. It is not a method recommendation layer and is not an execution-readiness claim.

Layer 2 is topic-specific method selection knowledge. It supports method comparison and selection logic within a defined task topic. It is not a command manual, parameter schema, execution surface, environment binding, or adapter-internal design.

Layer 1 inclusion does not imply Layer 2 recommendation. Layer 2 selection does not imply Layer 3/4 runtime support.
