# Layer 2 Formal Entry

This directory is the formal reading entry for Layer 2 method-selection artifacts.

Layer 2 formal files are compact agent-facing method-selection results. They help an agent choose methods within a selected Layer 1 analysis problem.

Layer 2 formal files are not commands, parameter schemas, environment bindings, adapter internals, default-method claims, or runtime-readiness claims.

## Current Standard

- `/mnt/NAS_21T/ProjectData/BioHarness/results/layer2/TOPIC_COMPLETION_STANDARD.md`: Layer 2 topic completion standard for working/evidence packages.
- `method_selection_standard.md`: formal Layer 2 method-selection presentation standard.

Formal topic files are created only after the corresponding working/evidence artifacts are complete. Unfinished topics should not have formal method-selection drafts here.
